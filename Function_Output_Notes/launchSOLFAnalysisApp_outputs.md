# launchSOLFAnalysisApp outputs

`launchSOLFAnalysisApp` is a convenience launcher for the MATLAB app.

## Output

| Output | What it represents | What it means physically or operationally |
| --- | --- | --- |
| `app` | Handle to the `SOLFAnalysisApp` instance. | This is the live app object, which lets MATLAB manage the graphical workflow for selecting files and running analyses. |

## Physical interpretation

This function has no scientific measurement output of its own. It simply starts the user interface.
